# Roblox "In This World" story videos

Everything from the first Claude chat that built Script 1 ("The balloons") and the v1 video.

Start here:
1. `HANDOFF.md`: current status, preferences, v1 vs reference comparison, v2 plan, how Claude drives Blender.
2. `PLAYBOOK.md`: trend research, story structure, titles, Script 1 final, Scripts 2 and 3 premises.
3. `CHAT_HISTORY.md`: what happened in the original chat, with every message from Kalid.

To continue with Claude on any account: attach or link this repo and say "Read HANDOFF.md and continue the project."

| Path | What |
